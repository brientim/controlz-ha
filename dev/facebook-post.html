ControlZ HA: Rooms and Tiles for Home Assistant 🏠

ControlZ-style room tiles for your Home Assistant dashboard, built automatically from your Areas.

  • Available in the Marketplace. Install it from Settings → Marketplace in one click, and updates show up under Settings → Updates.
  • Set up automatically, out of the box. Add one line (type: custom:controlz-rooms) and it builds the whole dashboard from your Areas: All Rooms, one page per room, Favorites and Automations. There's nothing to lay out by hand.
  • Resizable. A scale slider runs from 50% to 120%, with quick 60 / 80 / 100% buttons. Everything shrinks together, so you can fit more tiles on a wall tablet without anything looking squashed.
  • 3 tile sizes. Choose Large, Thin or Compact. Each size has a fixed height, so the grid always stays neat.
  • Saved per device. A wall tablet can use Compact with the sidebar while your phone keeps Large tiles with tabs.
  • Security banner at a glance: Insecure, Check, Motion or Secure.
  • Favorites for each person. Every household member keeps their own list, on every device.
  • Automations by room. Run, enable or disable them, and create simple new ones without leaving the dashboard.
  • Room sidebar or tabs, plus light, cover, fan and thermostat controls in ControlZ style.

📌 Note: Since Home Assistant 2026.11, HACS is built in as the Marketplace (Settings → Marketplace). It's the same catalog under a new name. If you're still on 2026.10 or older, add the repo in HACS as a custom repository with type Dashboard.
